# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in SQLTok, please report it responsibly.

1. **Do not** open a public issue on GitHub for the vulnerability.
2. Email the maintainer at `shoval.benjer@gmail.com` with the subject `SECURITY: SQLTok`.
3. Include a description of the vulnerability, steps to reproduce, and any suggested fixes.

You should receive a response within 72 hours. Please allow up to 7 days for a patch or mitigation to be published.

## Disclosure Process

- Reports are acknowledged within 72 hours.
- A fix is prepared and tested privately.
- The reporter is credited in the release notes unless anonymity is requested.
- A security advisory is published on GitHub once a patch is available.

Thank you for helping keep SQLTok and its users safe.
